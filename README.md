## Featured Projects

### 🔬 [MARS – Memory-Augmented Research System](https://github.com/Shivani176/MARS)
Production-grade agentic research system with a 3-layer memory architecture and hybrid BM25 + MPNet retrieval. Built a standalone evaluation framework achieving **95% citation verification** and **2x source coverage**, outperforming Consensus and Elicit across all benchmarks.
`Python` `LangChain` `LangGraph` `BM25` `ChromaDB`

### 🛡️ [RagShield – LLM Security Framework](https://github.com/Shivani176/RagShield)
Empirical AI safety framework for agentic RAG systems. Executed indirect prompt-injection attacks reaching **100% attack success rate**, then engineered defenses that cut it to **0% with zero utility loss**, validated through a 3-condition ablation study.
`Python` `LangChain` `ChromaDB`

### 🌐 [Chord DHT – Distributed Hash Table](https://github.com/Shivani176/chord_dht_udp/)
Fault-tolerant distributed hash table implementing the Chord protocol from scratch over UDP. Achieved **O(log N) key lookups** via 160-entry finger tables with SHA-1 consistent hashing, with automatic ring repair and key redistribution across a 5-node peer-to-peer network.
`Python` `UDP Sockets` `Consistent Hashing`

### 🎯 [VisionStack – Object Detection & HOI Analysis](https://github.com/Shivani176/VisionStack)
Lightweight SSD object detector built from scratch with custom IoU-based NMS, extended with zero-shot HOI detection using a VLM, improving average F1 by **+0.49**.
`Python` `PyTorch` `OpenCV`

### 🌀 [Diffusion Model Implementation – DeepFloyd IF](https://github.com/Shivani176/DeepFloydIF)
Full DDPM forward/reverse diffusion pipeline with Classifier-Free Guidance and SDEdit image-to-image translation. Reproduced the Visual Anagrams algorithm (CVPR 2024) to generate dual-orientation optical illusions.
`Python` `PyTorch`

### 🤖 [LangFormer – Transformer for Neural Machine Translation](https://github.com/Shivani176/LangFormer)
Transformer-based NMT model built entirely from scratch, achieving a **22% BLEU improvement** over the Seq2Seq baseline through systematic hyperparameter search.
`Python` `PyTorch`

### 🎨 [StableGAN](https://github.com/Shivani176/StableGAN)
DCGAN for synthetic data augmentation with ~30% fewer collapse modes.
`Python` `PyTorch`
